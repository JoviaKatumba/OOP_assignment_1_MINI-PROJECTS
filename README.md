## Setup

Requires Python 3.10+ (developed and tested on Python 3.12.3, Windows 10).

```bash
git clone <this-repo-url>
cd <repo>
python -m venv .venv
# Windows:  .venv\Scripts\activate      macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
```

## Running

**Tests** (from the repository root):

```bash
pytest            # 81 tests, about 5 seconds
```

**Notebooks:** open them with `jupyter lab` (or `jupyter notebook`) from the repository root and use *Kernel → Restart & Run All*. Run them from the root, because they import `src.*` and read `data/` with relative paths. To execute all of them headlessly:

```bash
jupyter nbconvert --to notebook --execute --inplace project*.ipynb
```

* No notebook needs internet access. Project 4 reads the NASA POWER data from `data/`. To refresh it, run `python scripts/fetch_nasa_power.py`.
* Project 2's interactive `input()` mode uses scripted answers by default, so *Run All* never blocks. Set `INTERACTIVE = True` in that cell to type the values yourself.
* All randomness uses `np.random.default_rng(seed)` with fixed seeds, so results are reproducible. The only output that changes between runs is the `timeit` timing in Project 2.

## Summary of findings

Full analysis is in each notebook's *Findings & Limitations* section.

**1. District population forecaster.** The exponential (CAGR) model beat the linear trend and the Fibonacci-ratio model on the 2022–2024 hold-out in all five districts (MAPE 0.3–2.0%). Wakiso grows fastest (6.5% a year) and needs the most new classrooms by 2029 (about 2,090 of about 4,870 in total). Gulu's growth is accelerating, so its forecast is likely an underestimate. The forecast series has a smaller variance than the history. That reflects a shorter span with no noise, not greater certainty, so the uncertainty is shown with 1,000-resample bootstrap intervals instead. The Fibonacci-ratio model implies about 62% annual growth and is not defensible for human populations.

**2. Solar micro-grid.** The system is well-posed (det = −5, κ ≈ 5.83). Even so, 3 of 30 days, all weekends, need negative battery output. These are repaired with NNLS, which leaves less than half the residual of clipping. The battery is far more volatile than solar (CV 0.62 against 0.08) and makes up 51% of the UGX 283k monthly cost while supplying only a quarter of the energy. Monte Carlo sensitivity reaches the κ bound: ±5% demand noise moves battery output by about ±58%. Vectorised solving is 14–20× faster than a loop. A linearly dependent third equation makes `scipy.linalg.solve` return an arbitrary answer with only a warning, so the class checks the matrix rank up front.

**3. Fish stock and export risk.** Fibonacci growth ignores carrying capacity and harvesting. Under the logistic model, h = 0.20 = r/2 achieves MSY (1,000 t/week). h = 0.30 over-fishes: it yields the same 750 t/week long-run catch as h = 0.10 from a stock a third the size. A variance threshold is meaningless because variance is measured in UGX², while CV is unit-free. Risk is *Moderate* under all policies, and the 5% VaR at h = 0.10 is UGX 78 bn (17%) below expected annual revenue. An 8-week closed season raises 5-year revenue only when the fishery is over-exploited (+7% at h = 0.30, −9% to −15% otherwise).

**4. Rainfall and crop suitability.** Cosine similarity is implemented correctly (it matches `1 − scipy.spatial.distance.cosine`, unlike last year's `math.cos`). It is scale-blind: Kampala against "twice-as-wet Kampala" scores exactly 1.0. Pearson correlation and Euclidean distance are more useful for crop advice. A circular `find_peaks` with a dry-spell merging rule correctly classifies Kampala and Mbarara as bimodal and Gulu as unimodal, on both the illustrative data and real NASA POWER data for 2014–2023 (*extension, extra credit*). The real data show large year-to-year variability: only 34–45% of month-years fall in each crop's window. The notebook includes an advisory note for Mbarara farmers (beans in both seasons, maize in the September season).

**5. Taxi routes.** The Ntinda equilibrium fare is UGX 2,200 (Q* = 76). The current UGX 2,000 fare leaves a shortage of 10 passengers per trip-hour. Walk-forward backtesting tunes SES to α = 1 (naive forecasting), which beats the original 3-day moving average by 22–38%. The linear trend is worst everywhere. On day 11 each route needs one vehicle (40–57% load), which suggests over-capacity, or that the counts are not truly daily. In the 60-day weekly simulation, seasonal-naive forecasting cuts MAE by 63% compared with the moving average.

## Data sources

* **Illustrative data** from the assignment brief: Projects 1, 4 and 5 core data, and Project 3 parameters.
